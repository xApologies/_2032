# Clover

Epistemic status: **DESIGN HYPOTHESIS**. Bootstrap date: 2026-09-21.
Source: SRC-0001; generated design elaborations are proposals, not adopted decisions.

## Education research questions

Investigate human-AI collaborative learning, demonstrated mastery, accessibility,
student portability, teacher participation, privacy, security, educational sandboxes,
evidence-based evaluation, and institutional interoperability. Keep technical and
empirical evaluation independent of political rhetoric.

## Proposed first evaluation

Begin with synthetic learners and public materials. Co-design a bounded learning
task with teachers; compare conventional instruction support and AI-assisted support
using the same learning objectives and assessment rubric. Measure demonstrated
mastery, retention, transfer, teacher workload, accessibility, and erroneous feedback.
Portability tests export learner-controlled records without vendor dependence.

Before any real learner pilot, resolve consent, privacy, retention, age-appropriate
oversight, institutional review, and teacher/student withdrawal processes with qualified
reviewers. Do not collect real student data in this repository.
Reject designs that improve speed while reducing mastery or accessibility. No pilot
results or education effectiveness claims are established by this bootstrap.
