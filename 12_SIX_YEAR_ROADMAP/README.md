# Six-year roadmap

Epistemic status: **DESIGN HYPOTHESIS**. Bootstrap date: 2026-09-21.
Source: SRC-0001; generated design elaborations are proposals, not adopted decisions.

## Evidence-gated planning windows

| Window | Focus and deliverable | Exit evidence |
| --- | --- | --- |
| 2026–2027 | Foundations, architecture, provenance contracts, baseline protocol | Traceable records and reviewed scope; baseline executable. |
| 2027–2028 | Human-AI workflow prototypes and educational sandboxes | Public/synthetic end-to-end demonstrations and failure logs. |
| 2028–2029 | Controlled pilots and measurement | Approved protocol, appropriate participant protections, reproducible analysis. |
| 2029–2030 | Institutional modeling, lifecycle costs, governance, security, privacy, records, implementation | Alternatives, cost ranges, dependencies, independent reviews, unresolved authority register. |
| 2030–2031 | Stress/adversarial testing, recovery, disagreement, bad data, model failure, continuity | Measured failure behavior and successful recovery exercises. |
| 2031–2032 | Mature public specification | Evidence, limitations, unresolved questions, implementation alternatives, reproducible evaluation. |

Windows overlap intentionally; progression depends on evidence, not the calendar.
Dependencies: provenance before evaluation; baseline before superiority claims;
privacy/security review before real participants or sensitive data; controlled
results before scale. A failed gate returns the design to revision or rejection.
This roadmap contains no election predictions or assumption of public office.
