# War Room

Epistemic status: **DESIGN HYPOTHESIS**. Bootstrap date: 2026-09-21.
Source: SRC-0001; generated design elaborations are proposals, not adopted decisions.

## Interaction requirements

Support spoken reasoning while pacing, large visual surfaces, source comparison,
timelines, maps, model visualization, disagreement visualization, and provenance
inspection. Human advisers enter the same authorized working context with explicit
attribution. Offer text, captions, keyboard operation, and low-stimulus layouts.

| Utterance | Proposed response |
| --- | --- |
| What changed? | Timestamped delta from the selected prior brief, including corrections. |
| Why do we believe that? | Claim, inference, evidence, uncertainty, and conflicting sources. |
| Show me the original source. | Exact source version and locator, or a clear unavailable state. |
| Who disagrees? | Attributed dissent and unresolved differences; no invented consensus. |
| Separate evidence from inference. | Distinct labeled evidence and reasoning panes. |
| What requires presidential authority? | Human-reviewed authority question, scope, and unresolved legal review. |
| Send this question back to the responsible domain. | Confirm recipient and permitted content, then record routing receipt. |
| Record the decision. | Read back scope, rationale, alternatives, and authorizing human before confirmation. |
| Compare predicted and observed outcome. | Paired measures, time window, missing observations, and confounders. |

Test speech ambiguity, noisy-room transcription, adviser disagreement, and inaccessible
visualizations. No ambiguous voice command becomes authorization. A mistaken transcript
is correctable with history retained. Room display and capture need explicit access
and privacy controls; implementation remains open.
